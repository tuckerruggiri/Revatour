# Revatour desktop

A small always-on-top clock. Click it and the full Revatour opens. Press **Shrink to clock** (Trading Day page) to go back.

**Get the app:** GitHub > Actions > "Build desktop app" > latest run > download `revatour-macos-latest` (Mac, .dmg) or `revatour-windows-latest` (Windows, .exe).

- Mac: open the .dmg, drag Revatour to Applications. First time: right-click the app > Open (it is not signed).
- Windows: run the .exe. If SmartScreen warns, press More info > Run anyway.

Drag the clock by the dotted grip on its left. Right-click it (or press the ... button) for Always on top, Opacity and Quit.

Run locally: `cd desktop && npm install && npm start`.
